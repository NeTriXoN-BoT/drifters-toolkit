# Security reports

Report suspected vulnerabilities through [GitHub’s private reporting form](https://github.com/NeTriXoN-BoT/drifters-toolkit/security/advisories/new). Keep exploit details and sensitive files out of public issues. If the private form is unavailable, open an issue asking for a private security contact without describing the vulnerability.

Include the affected version and platform, a concise description of the impact, reproduction steps and a small synthetic example if possible. Archive handling, package paths, update verification, recovery, the native interface bridge and save decoding are particularly useful areas to describe precisely.

Do not send credentials, signed download links, real saves, game assets or memory dumps. Redact account details and personal paths from logs and screenshots.

Security fixes target the current stable version. Older releases may need an update rather than a separate backport. This is a community project; response times and a bounty are not promised.

The Linux AppImage bundles Qt WebEngine and other libraries. Report issues affecting the distributed application here, and identify an upstream report when one exists. Windows WebView2 Runtime is serviced separately by Microsoft.
